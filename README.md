# Análise de Segmentação de Clientes com Pandas

## 📌 Objetivo
Este projeto tem como objetivo analisar o comportamento de clientes com base em idade e valor de compra, identificando diferentes perfis para apoiar decisões de negócio.

## 🧰 Tecnologias utilizadas
- Python
- Pandas

## 📊 Análises realizadas

### 🔹 Segmento jovem
Clientes com idade inferior a 30 anos.

### 🔹 Clientes de alto valor
Clientes com valor de compra acima de 100 e idade superior a 30 anos.

### 🔹 Clientes de baixo potencial
Clientes com valor de compra menor que 200 ou idade inferior a 25 anos.

## 💡 Insights

- Clientes acima de 30 anos tendem a apresentar maior valor de compra
- A segmentação permite identificar grupos com diferentes comportamentos
- Estratégias podem ser direcionadas para públicos específicos

## 🚀 Conclusão

A análise de dados permite entender melhor o perfil dos clientes e tomar decisões mais estratégicas, como campanhas direcionadas e ações de retenção.
